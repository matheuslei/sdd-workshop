# Quickstart: validar o Simulador do Workshop SDD

Pré-requisito: nenhum. Abra `index.html` com duplo clique (Chrome ou Edge).

1. **Trilha**: escolha OpenCode → o mapa mostra 4 áreas com progresso 0%.
2. **Instalação (US1)**: em Simulador de instalação, para cada etapa clique Copiar, cole no
   terminal e Enter. Esperado: saída com selo "saída ilustrativa" e próxima etapa liberada.
   - Cole `uv --version` na etapa do uv → dica, não avança.
   - Na etapa da chave, cole `sk-or-v1-` + 64 caracteres hex → alerta; nada aparece na tela.
   - Concluir → "Ambiente pronto". Troque para Claude Code → etapas comuns seguem feitas.
3. **Projeto (US2)**: cole Passo 0 e os prompts. A árvore ganha constitution.md, spec.md,
   plan.md, tasks.md e código; clique em cada arquivo para ler. Clarify: use os atalhos.
   `uv run python main.py` → botão "Abrir no navegador".
4. **App (US3)**: crie "Beber água", marque hoje, recarregue (F5) → marcação mantida.
   Volte uma semana, arquive, restaure, exclua (pede confirmação).
5. **Guia e prompts (US4)**: Copiar mostra "Copiado!".
6. **Problemas (US5)**: dispare "SSL" e cole a correção → sucesso.
7. **Assistir/Reiniciar (US6)**: modo Assistir conclui sozinho; Reiniciar zera tudo.
8. DevTools: console sem erros em todas as páginas; largura 375px sem rolagem lateral;
   alternar tema claro/escuro.
