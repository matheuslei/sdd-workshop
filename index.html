Workshop SDD com Spec Kit, no navegador

Não conseguiu instalar o ambiente a tempo? Sem problema. Aqui você faz todo o workshop numa simulação: instala as ferramentas num terminal de mentira, cola os prompts /speckit.* e vê o projeto Monitor de hábitos ficar pronto. Nada é instalado no seu computador.

1. Escolha sua trilha

2. Siga o caminho

Como funciona: cada etapa mostra o comando com o botão Copiar. Cole no terminal simulado e pressione Enter. Se o comando não conferir, aparece uma dica. Travou? Use Preencher para mim ou Executar por mim. No celular, toque em ▶ Executar, no rodapé. Quer só acompanhar? Use ▶ Assistir.
🔐 Nunca cole chaves, senhas ou tokens reais aqui. A simulação usa a chave falsa sk-or-FALSA-curso-sdd. Se colar algo com cara de chave real, o simulador descarta e avisa.
